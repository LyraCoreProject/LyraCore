# T2d taxi comparison

The local wire run completed the flight but did not match the Golden Trace. The comparator reported
91 rule differences. None is a Deliberate Deviation. The node catalogue has one separate data
difference. No gameplay correction is included in T2d.

  The [taxi evidence](https://github.com/LyraCoreProject/wire-harness/blob/c24ebb3c69613c7d442cc737f199e7a1f181da52/docs/taxi.md)

  classic-db source `cd0c426a3b2ff56dd518bf009025299468e60fdb` supplied creature template 352 and
  mount creature 541's display 6852. The source dump's SHA-256 matched `classic-db.lock`.

positions. The comparator preserves reply order, so missing replies and repeated splines also cause
later packets to compare at different flight positions. The 75 coordinate differences below do not
mean that 75 imported coordinates are wrong.

The wire trace's dismount field update arrives at 72,547 ms; the reference's arrives at 73,556 ms.
This is supporting timing evidence. It does not replace the required landing correction or change
the comparator's packet-timing rule.

## Data difference

The imported destination node uses X = -10628.8896484375. The reference landing correction uses
X = -10628.900390625. This 0.0107421875-yard difference comes from DBC versus database node
coordinates. The imported Y and Z agree with the reference. The Character ends at the imported
node. The candidate sends no landing correction, so this data difference is a durable-position
observation rather than one of the 91 comparator records. It does not count against conformance.
